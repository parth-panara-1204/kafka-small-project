to run this project, you will need,
1. npm
2. docker

first, follow this tutorial https://kafka.apache.org/quickstart/. pull docker image, and download kafka scripts.
run kafka docker image in one terminal.
create a topic through kafka scripts(find it in tutorial).
now run a consumer(find it in tutorial).

now navigate to this folder in the terminal, and run node server.js.
open index.html in browser.

notice, click streams in the terminal where consumer is running, as you click the button!

all done!
